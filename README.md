# modelSelector: Efficient Criterion Based Model Selection in Python

The `modelSelector` Package offers a variety of functions for criterion based model selection in python.

## Features
The Package supports:
- Various Model Selection Criteria: AIC, AICc, BIC, Mallow's Cp.
- Various Model Types, including ready made interfaces to  *linear* and *logistic regression* models via `scikit.learn`, as well as `pyPesto` for more complicated models.
- Easy implementation of *custom objectives*.
- Standard selection algorithms, like forward, (efficient) backward, exhaustive, and efficient exhaustive.
- Visualization Routines for visualization of results.

## Installation
From `pip` via
```shell
pip3 install modelSelector
```
or from GitHub via
```shell
git clone <insert repo here>
pip3 install .
```
